## 3. S18 完成能力

### 3.1 IAM Permission Reference

- IAM 服务间批量只读校验 API；
- `ENABLED / DISABLED / UNKNOWN` 完整状态；
- OAuth2 `client_credentials`；
-精确 Scope `iam.permission-reference.read`；
- System 不复制 Permission、Role、Assignment 或用户授权状态。

### 3.2 Catalog 发布事务

```text
事务外候选快照
→ 事务外 IAM 权威校验
→ 本地事务内重新校验 Draft/Version/Checksum
→ Release + Published Pointer + Outbox 原子提交
```

- Feign 强制事务外；
- 无 Seata；
- 无 `@GlobalTransactional`；
- Draft 竞态或 Permission 变化 Fail Closed。

### 3.3 Runtime Cache

已缓存：

- Catalog 不可变 Release Snapshot；
- Dynamic I18n 单 Locale Release；
- Parameter 有效解析结果；
- Dictionary Active List / Resolve Result。

明确不缓存：

- User Preference；
- IAM Permission Validation 结果；
- `/catalog/me` 用户最终过滤响应。

Redis 故障回源 PostgreSQL；PostgreSQL 故障时不只凭旧 Cache 返回结果。

### 3.4 可靠变更通知

- System Flyway V9：Outbox / Inbox；
- Spring Cloud Stream + RocketMQ；
- Catalog、I18n、Parameter、Dictionary 六类事件；
-业务事实与 Outbox 同一本地事务；
- Inbox 幂等；
- Broker 中断 RETRY，恢复后补发；
-毒消息进入 DLQ；
-多实例 Cache 失效。

### 3.5 Permission 对账

- 默认每 10 分钟对已发布 Permission Reference 只读对账；
-低基数指标与脱敏告警；
-不自动改写 Catalog；
- IAM 停机不影响 System Readiness。
