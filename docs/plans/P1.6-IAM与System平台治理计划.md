## 3. 已完成架构状态

### 3.1 IAM

IAM 继续 Own：

- Account、Credential、UserType；
- Role、Permission、Assignment；
- OAuth Client、Authorization、Session、Refresh、JWT Claims；
- Factory Scope 和 Party Binding。

IAM 为 System 提供 Permission Code 批量只读验证 API，System 使用 OAuth2 `client_credentials` 和精确 Scope 调用。

### 3.2 System

System 继续 Own：

-非敏感类型化参数；
-非权威受限通用字典；
- Dynamic I18n Draft、Release 和 Runtime；
-用户显示偏好和受限 View；
- Application Catalog、Navigation Metadata、发布历史；
-上述 Runtime Cache 和可靠变更通知。

System 不保存 IAM Permission 定义、Role、Assignment、用户授权结果或 OAuth Client 安全配置。

### 3.3 S18 事务模型

```text
事务外 Catalog 候选构建
→ 事务外 IAM Permission 权威校验
→ System 本地事务重新校验 Draft/Version
→ Release + Published Pointer + Outbox 原子提交
→ 事务外 RocketMQ 发布
→ Inbox 幂等消费
→ Redis Cache Evict
```

-不使用 Seata；
- Feign 不进入数据库事务；
- Redis/RocketMQ 不进入业务事务；
- PostgreSQL 是唯一权威；
- Redis 故障回源 PostgreSQL；
- PostgreSQL 故障不返回不可信 stale Cache。
