# P1.6 IAM 与 System 平台治理计划

- Head：`phase/p1.6-system-platform`
- Base：`main`
- S00 基线 SHA：`5562e5ec1c4340dc2de0c5c80f54135df2ae6454`
- 当前阶段：里程碑 B 已完成；S00～S10 `Completed`，S11 `In Progress / Awaiting Chris Decision`，S12 `Not Started`

## 1. 目标与边界

P1.6 先建立可信工程与规范基线，再基于真实调用方证据收敛 IAM，随后建设 System Platform MVP，并在最终封板前统一完成 Mobile、正式环境和跨仓库集成验收。S00 只处理安全默认值、自动门禁、规范缺口和阶段治理；不重构 IAM，不创建 `mom-system-platform`，不冻结 IAM/System/MDM 最终领域边界。

阶段约束：

1. 每个 Slice 独立提交、验证、Review，完成后停止，不自动进入下一 Slice。
2. S01～S05 不提前实现 System 业务。
3. S06 前不得开始 IAM 大规模重构。
4. S07 已接受 ADR-024 并完成架构决策收口；S08、S09 已按行为保持门禁完成。
5. S10 只封板 IAM 平台安全基线，不把正式 Mobile/App Link、真实环境和发布级 E2E 作为 System Platform 的前置条件。
6. S10 平台安全基线未完成前不得开始 System Server；S10 完成后仍需独立指令才能进入 S11。
7. S11 必须明确 Warehouse 归 WMS、设备台账归 EAM，并裁决 IAM、System、MDM 的权威数据边界。
8. S15 没有真实动态国际化资源调用方时直接推迟。
9. Spring Authorization Server 官方 JDBC Store 和 P1.5 安全能力不因技术栈统一而重写。
10. S19-A 必须回收全部延迟集成项；未关闭时不得将 PR #33 转为 Ready、合并 main 或宣称 Mobile/正式环境生产可用。

## 4. S07 Accepted 决策边界

1. ADR-024 状态为 Accepted，ADR-019 状态为 Superseded by ADR-024。
2. PC 第一方 JSON 与 Mobile Authorization Code/PKCE/OIDC 双通道长期并存。
3. 两条 Adapter 共享 IAM 内部唯一的账号认证、授权上下文、Session、Refresh、JWT Claims、Token 签发和撤销核心。
4. PC JSON Login 不是 Password Grant；禁止 `grant_type=password` 和自定义密码 Grant。
5. 用户名和密码只能由 IAM 接收和校验；普通业务服务、Gateway、System、MDM、WMS、QMS、Integration、Mobile 和第三方服务不得校验或长期持有密码。
6. Role、Permission、Factory、Party、User Type、Session Context 和授权 Claims 只能由 IAM 权威数据加载。
7. 可以在 S08 行为保持前提下评估 `IamFirstPartyLoginApplicationService`、`IamAuthorizationContextLoader`、`IamJwtClaimsAssembler`、`IamAccessTokenIssuer` 等职责。
8. 可以评估复用 SAS `OAuth2TokenGenerator`、`JwtGenerator` 或等价组件，但不得改变 Claim、签名、`kid`、TTL、Session、Refresh、撤销或外部协议行为。
9. 禁止第一方 JSON Controller 通过内部 HTTP 调用自己的 `/oauth2/token`。
10. Web 标准 PKCE Package 状态为 `Compatibility / Future Migration Capability`，当前不删除、不接线、不描述为生产 Runtime。
11. Mobile Logout 的目标安全语义已接受，具体客户端实现和 E2E 迁移至 S19-A。
12. Redirect URI 精确登记、禁止通配和分环境矩阵已接受；正式值与 E2E 迁移至 S19-A。
13. EG-02 业务 Resource Server revoked sid 等价能力已在 S10 关闭。
14. S08、S09、S10 不得改变 ADR-024 冻结的外部协议与安全语义。

## 5. S08 进入条件与禁止项

S08 只能在独立任务中启动，并且必须先再次核验：

- ADR-024 仍为 Accepted；
- S08 仍为 Not Started；
- 阶段分支、PR 和 CI 可信；
- 没有其他执行者已经开始同一 Slice；
- 本次实现范围不包含新增公开 API、协议迁移或 Token/Session 模型变更。

S08 不得：

- 修改 JSON API 路径、请求、响应或错误契约；
- 修改 OAuth2/OIDC 标准端点或响应；
- 增加 Password Grant 或自定义密码 Grant；
- 通过 HTTP 调用自身 `/oauth2/token`；
- 修改首次改密、Login、Refresh、Logout、Claim、签名、TTL、Session、Rotation、Reuse Detection 或 revoked sid；
- 修改 Permission、Gateway 或 Resource Server 运行时；
- 删除 Adapter；
- 自动进入 S09。

若复用 SAS Token 组件导致任何行为变化，必须停止该部分，记录结果和影响，并在继续前取得 Chris 明确批准。
