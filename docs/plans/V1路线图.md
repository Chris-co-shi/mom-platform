# MOM Platform V1 路线图

当前完成状态见 [当前实现地图](../当前实现地图.md)。本路线图只描述未来业务交付顺序，不把规划写成现状。

## 目标

以可重复演示的垂直切片完成供应商到货、生产执行、成品发运和批次追溯闭环，并验证权限、数据所有权、幂等、失败恢复和可观测性。

## 路线

| 阶段 | 业务结果 | 主要领域 |
|---|---|---|
| 管理平台基线 | 认证授权、System V1、MDM 静态主数据和 Web 管理端 | Auth、System、MDM、Web |
| 到货与来料检验 | 送货通知、实物收货、检验处置、库存质量状态 | Integration、WMS、QMS、MDM |
| 生产执行 | 工单、定义快照、预占、投料、过程与产出 | MES、WMS、MDM、PCS |
| 放行与发运 | 成品检验、放行、自动入库、拣货与发运 | QMS、WMS、WCS |
| 追溯与演练 | 正反向追溯、影响分析、模拟召回和故障恢复 | Traceability、Integration、Operations |

## 下一阶段前置决策

- 首个业务 Slice 的参与角色、触发事件和成功结果；
- WMS 收货与库存事实模型；
- QMS 检验状态机及其对 MDM 已发布质量标准的引用方式；
- 重复请求、部分成功、MQ/DB 故障的可见行为；
- Web/PDA 的实际入口和权限范围。

这些决策未确认前，不预建 Saga、通用工作流、动态状态机或跨服务事务框架。

详细业务顺序见 [V1 垂直切片计划](V1垂直切片计划.md)。
