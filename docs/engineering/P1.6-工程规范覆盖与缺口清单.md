## 优先级结论

1. S01～S05 均为规范与门禁 Slice，不提前建设 System 业务。
2. S03 只规范 IAM 安全配置和协议边界，不删除、合并或重写既有认证入口。
3. 现有 Spring Authorization Server JDBC Store、Refresh Rotation、Reuse Detection、Session 撤销与 JWT 校验均保持。
4. 国际化动态资源、复杂弃用平台和跨仓库契约生成若无真实调用方，分别推迟到 S15 或 P1.7。
