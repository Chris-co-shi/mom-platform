## S06 结论

1. `docs/engineering/P1.6-S06-IAM端点调用方与职责审计.md` 是调用方与职责权威证据。
2. 三个 PC Web 当前使用第一方 JSON；Mobile 使用系统浏览器 Authorization Code + PKCE S256。
3. 标准 Refresh Grant 与 JSON Refresh 共享 `IamSessionTokenService`，不能按重复实现删除。
4. S06 未修改认证协议、API、Token、Session、Refresh、Permission、Schema 或 Flyway。

## S07 Accepted 结论

1. ADR-024 状态为 Accepted；ADR-019 状态为 Superseded by ADR-024。
2. PC 第一方 JSON 与 Mobile Authorization Code/PKCE/OIDC 双通道长期并存。
3. JSON Login 是第一方协议 Adapter，不是 Password Grant；禁止标准或自定义密码 Grant。
4. 密码只由 IAM 接收和校验；普通业务服务、Gateway、System、业务 Resource Server、Mobile 和第三方服务不得校验或长期持有。
5. User、Client Policy、Role、Permission、Factory、Party、Session Context 和 Claims 只由 IAM 权威数据加载。
6. 两条 Adapter 共享账号认证、授权上下文、Session、Refresh、Claims、Token 签发、撤销和 Fail Closed 核心。
7. `IamFirstPartyLoginApplicationService`、`IamAuthorizationContextLoader`、`IamJwtClaimsAssembler`、`IamAccessTokenIssuer` 已在 S08 按行为保持边界实现。
8. 标准端继续使用 SAS Generator；不得改变 Claim、签名、`kid`、TTL、Session、Refresh、撤销或外部协议。
9. 禁止 JSON Login 通过内部 HTTP 调用自身 `/oauth2/token`。
10. Web 标准 PKCE Package 产品状态为 `Compatibility / Future Migration Capability`。
11. EG-01：目标安全语义已接受；客户端实现/E2E 延迟至 S19-A。
12. EG-02：已在 S10 关闭。
13. EG-03：架构决策已关闭；正式 Client/Redirect/App Link 与 E2E 延迟至 S19-A。
14. EG-04：产品状态决策已关闭；当前不删除、不接线、不描述为生产 Runtime。
