# 计量单位工程规范

## 1. 所有权和编码

MDM 拥有单位目录、Quantity Kind/Dimension 和换算关系；业务领域保存实际数值、单位 Code 及必要快照；System 偏好只决定显示单位。单位 Code 稳定且不随语言变化，不使用中文或英文显示名作为 Code。

MOM 优先采用可满足工业语义的 UCUM Code。UCUM 无法无歧义表达的企业单位使用受控 `mom:` 扩展命名空间，并维护 UCUM 映射或“不适用”理由；S05 不引入单位框架或创建目录表。

## 2. 量纲与换算

单位必须属于明确 Dimension。禁止无密度将 kg 与 L 转换、用纯乘数处理摄氏温度、把百分比等同质量浓度，或让不同物料共用固定密度。

通用换算模型至少定义 multiplier、offset、precision、rounding、effective version。涉及物料、密度、温度、批次或有效时间的换算属于业务规则，不塞入通用单位表。换算失败必须明确失败，不能返回未标注单位的数值。

## 3. 历史事实与展示

关键业务事实保留原始值、原始单位，必要时同时保存标准值、标准单位和换算规则版本，避免规则变化重写历史。显示名可本地化为 `kg`、`千克` 或 `kilogram`，但 Code 不变。显示偏好不改变库存权威单位、设备协议单位、审计事实或量纲校验。

单位缓存必须可重建、有版本和 TTL；失败时回退业务标准单位，不能改变权威数值。UCUM 的语法和语义以 [官方规范](https://ucum.org/) 为事实来源。
