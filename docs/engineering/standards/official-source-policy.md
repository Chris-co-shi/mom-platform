# 官方技术来源政策

## 事实来源优先级

涉及 JDK、Spring Boot、Spring Cloud、Spring Cloud Alibaba 及其组件行为时，按以下顺序取证：

1. 对应版本的官方参考文档、规范和 API 文档；
2. 官方发布说明与兼容矩阵；
3. 官方源码、测试和配置元数据；
4. 官方 Issue、PR 和维护者说明；
5. 社区文章仅用于发现线索，不能单独作为架构结论。

Stack Overflow、博客、开源后台框架和模型记忆不得替代官方证据。

## 版本要求

技术结论必须写明适用版本。引用 `current`、`latest` 或 Snapshot 文档时，必须再次确认其内容与仓库锁定版本一致。

当前 MOM 核心基线：

- JDK 25；
- Spring Boot 4.1.x；
- Spring Cloud 2025.1.x；
- Spring Cloud Alibaba 2025.1.x。

## 官方事实与 MOM 决策

规范必须区分：

- **官方事实**：官方兼容矩阵、默认行为、弃用和移除信息；
- **MOM 决策**：基于制造业场景制定的超时、边界、默认关闭、测试门禁和失败策略；
- **MOM 已验证组合**：不在官方精确矩阵中，但已通过真实 Smoke Test 的版本组合。

不得把 MOM 的工程偏好描述为官方强制，也不得把一次编译成功描述为官方兼容。

## 升级规则

升级 JDK 或 Spring 版本时必须：

1. 阅读官方迁移指南和发布说明；
2. 核对 BOM、Release Train 和组件矩阵；
3. 检查弃用、移除、默认值变化和安全公告；
4. 执行静态基线、全 Reactor、真实基础设施和故障场景验证；
5. 在 PR 中记录官方来源、MOM 决策和仍未覆盖的风险。
