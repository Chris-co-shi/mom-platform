# 用户偏好准入边界

- 状态：Deferred
- 当前事实：System V1 未实现用户偏好，普通任务无需读取本文。

只有用户重新批准用户偏好 Slice 时，才使用本页作为设计检查入口；不得把历史 S16 方案当作已实现契约。

## 必须先决定

- 偏好所有权、允许覆盖层级和字段白名单；
- Locale、显示时区、主题、密度、分页大小等字段的默认值与回退；
- 用户身份来源、授权隔离、乐观版本和重置语义；
- Web/Mobile 的真实调用方、离线降级和兼容策略；
- Factory 业务时区、权限和数据范围不得被显示偏好覆盖。

## 禁止

- 在偏好中保存 Role、Permission、Scope、Token、Session、密码或服务端业务状态；
- 接受任意 JSON、脚本、SQL、正则、Java 类型或 Secret-like Key；
- 因为存在本规范就提前创建表、API、缓存或客户端接线。
