## 不自动化的 Review

- 真实 TLS、Ingress、Kubernetes Secret/ConfigMap RBAC 与网络策略属于部署环境证据。
- CORS 最终允许源、Cookie Domain/Path 与 Redirect URI 需要真实部署域名，不能由源码静态扫描证明。
- 业务 Resource Server 的最终对象归属与 revoked sid 等价机制需要逐调用链测试。
- Feign 操作是否幂等、是否位于事务内、Fallback 是否允许陈旧数据需要用例级 Review。
