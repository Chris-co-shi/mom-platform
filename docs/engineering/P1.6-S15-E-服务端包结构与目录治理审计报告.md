## 8. 未修复项与退出条件

### QUERY-002：IAM 普通 Mapper 返回 Application View

- 精确位置：第 5 节列出的 6 个 Mapper 及对应 IAM XML `resultType`。
- 风险：Persistence Mapper 依赖 Application 管理视图，未来读取模型演进可能扩大层间耦合。
- 未修复原因：本任务只允许 Package/目录行为保持重构；拆 QueryMapper、引入 Row 并映射 View 会修改查询接口和适配代码，且现有 S15-D 已锁定 SQL/管理行为。
- 状态：Accepted Exception，不授权新 Mapper 返回 Application/Web DTO。
- 退出条件：独立 IAM Query Projection 治理 Slice 提供专用 Row、Mapper/Repository 映射、9 个 XML PostgreSQL IT、管理行为特征测试和无协议变化证据。

### CONFIG-003：IAM 能力内聚配置

- 精确位置：第 5 节列出的 13 个 Admin/Bootstrap/Recovery/Security 类型。
- 风险：配置入口分散，查找成本高；不产生 Persistence Feature-first 或反向依赖。
- 未修复原因：多个内部配置和协议组件是 package-private；本 Slice 禁止无条件扩大可见性和 IAM 大规模业务重新分包。
- 状态：Accepted Exception。
- 退出条件：独立 IAM 包分层任务冻结安全协议子模块边界，证明 Bean 数量、Filter Chain 顺序、OAuth2/OIDC/SAS、Login/Refresh/Bootstrap 行为不变，并通过完整 IAM 安全回归。

除上述 Accepted Exception 外，无未修复 Package 结构问题。S16 仍为 `Not Started`。
