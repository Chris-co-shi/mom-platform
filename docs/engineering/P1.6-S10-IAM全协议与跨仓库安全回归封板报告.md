## 6. Gateway 与 Resource Server（EG-02）

Gateway 既有实现保持不变：独立验证 JWT/JWK/Issuer/Audience，清理客户端 `X-MOM-*`，校验 Client 路由和 revoked sid；Redis 失败返回 503，健康路径不依赖撤销 Store，Bearer 原样转发。

由于 mom-infra 不可用，S10 没有依赖“业务服务不可直连”的部署假设，而是采用路径 B，在共享 Servlet Resource Server 增加：

- `MomRevokedSessionChecker`：协议中立只读端口；
- `RedisMomRevokedSessionChecker`：Infrastructure Adapter；
- `MomRevokedSessionFilter`：在 `BearerTokenAuthenticationFilter` 后读取已验证 JWT 的 `sid`；
- active sid 放行；
- revoked 或缺少 sid 返回 Bearer 401；
- Redis 超时、连接失败或结果不确定返回 503；
- 配置公开路径跳过撤销检查；
- 不读取 Gateway Header，不调用 IAM HTTP，不写 Redis，不改变 TTL、JWT 或 Session 撤销事务。

组件测试覆盖业务服务直连、active/revoked/missing sid、503、公开路径和伪造 Header；真实 Redis 8.4.4 IT 覆盖 active、revoked 和连接不可用。

`EG-02: Closed at platform implementation/test boundary`
