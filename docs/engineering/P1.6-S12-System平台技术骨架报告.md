## 3. POM 依赖

### API

无直接依赖。当前只有包说明，不包含 DTO、业务枚举、Entity、Mapper、Repository、Feign Client、Spring Bean 或 Controller。

### Client

| 依赖 | 原因 |
|---|---|
| `mom-system-api` | 对应契约边界 |
| `mom-openfeign` | 现有全部领域 Client 统一调用基础设施 |

当前没有真实 Feign 接口、调用配置或业务错误映射。

### Server

| 依赖 | Scope | 选择原因 |
|---|---|---|
| `mom-system-api` | compile | 本领域契约边界 |
| `mom-webmvc` | compile | 统一 Servlet/Spring Boot 运行宿主 |
| `mom-tracing` | compile | 现有普通服务公共追踪基线 |
| `mom-metrics` | compile | 现有普通服务公共指标基线 |
| Nacos Discovery Starter | compile | 统一服务发现能力；默认关闭 |
| `mom-test` | test | JUnit、Spring Boot Test、AssertJ 与 ArchUnit 测试基础 |

Spring Boot Maven Plugin 沿用根 pluginManagement 的 `4.1.0` 与 exec classifier 规则。

明确未采用：`mom-security`、`mom-data`、`mom-outbox`、`mom-seata`、`mom-messaging`、RocketMQ、Redis、MyBatis/MyBatis-Plus、JPA、JDBC、Flyway、PostgreSQL Driver、`mom-iam-client`、`mom-mdm-client`、`mom-integration-client` 及任何 `*-server`。

`mom-security` 当前会传递引入 Redis。S12 没有业务端点且禁止 Redis，因此不在空骨架预埋；后续出现真实业务 API 时，必须由对应 Slice 同时完成安全边界、失败语义与测试。

## 4. Java 包结构

包根为 `io.github.chrisshi.mom.system`：

```text
web → application → domain
infrastructure → domain/application ports
```

S12 使用 `package-info.java` 登记四个边界，不创建占位 Service、Port、Controller、Entity 或 Repository。唯一生产类为 `MomSystemApplication`，采用仓库统一 `@SpringBootApplication` 模式；没有 `@MapperScan`、`@EnableFeignClients`、消息监听、定时任务或额外自动配置。

## 5. 基础配置

`application.yml` 只设置：

- `spring.application.name=mom-system-server`；
- `spring.cloud.nacos.discovery.enabled=${NACOS_DISCOVERY_ENABLED:false}`。

未冻结端口；未配置数据库、Redis、MQ、Seata、Client Secret、JWT Key、Nacos 凭据、Namespace 或正式域名。Discovery 默认关闭，空骨架启动不依赖外部 Nacos。

## 6. 测试骨架

`MomSystemApplicationTest` 使用 `ApplicationContextRunner` 创建轻量非 Web Context：

- 不绑定端口；
- 不启动容器；
- 不访问网络或外部中间件；
- 断言 Context 无启动失败；
- 断言唯一启动配置类存在；
- 断言不存在 `DataSource` Bean。

测试没有 `@Disabled`、空断言、跳过参数或虚假连接配置。

## 7. POM XML 语义门禁

`SystemPlatformPomArchitectureTest` 使用 XML DOM 解析实际 POM，覆盖：

1. 根 Reactor 精确注册一次 System；
2. 聚合 packaging 与三个精确子模块；
3. 聚合模块无业务依赖；
4. API 无依赖且只有包说明；
5. Client 只允许 System API 与 `mom-openfeign`；
6. Server 使用精确最小白名单，`mom-test` 必须为 test scope；
7. System 源树无业务类型、SQL、Migration 或 Mapper 资源；
8. `invalid-system-server.xml` 负例 Fixture 声明 `mom-iam-server`，同一语义校验必须精确拒绝。

通用 `MavenModuleDependencyArchitectureTest` 继续自动验证全 Reactor 的 API/Client/Server 方向。

## 8. ArchUnit 门禁

`mom-architecture-tests` 以 test scope 引入 `mom-system-server`，让通用生产字节码扫描覆盖 System：

- Domain 禁止依赖 Web、Infrastructure、Spring Web、JDBC、MyBatis、Feign、Redis 与 Servlet；
- System Application 禁止依赖 Web 或 Infrastructure 实现；
- System Web 禁止越过 Application 直接依赖 Domain/Infrastructure；
- Domain 不得依赖 Infrastructure；
- System 全包禁止依赖 IAM Application、Web、Repository、Mapper 或 Infrastructure；
- Controller 通用规则继续禁止直接依赖 Mapper、Repository 或 Entity。

空包允许当前无匹配业务类；包目录存在性另由 S12 文件语义门禁强制。未来加入真实类后，同一 ArchUnit 规则自动生效。
