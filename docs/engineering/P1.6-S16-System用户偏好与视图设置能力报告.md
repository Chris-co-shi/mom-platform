## 3. 所有权与授权边界

冻结：`Preference ≠ Authorization ≠ Business Fact ≠ Master Data`。

- System 唯一拥有用户显示偏好与受限视图设置；IAM 仅通过已验证 JWT `sub` 提供用户稳定引用。
- URL、Query、Body 和 Header 均不能提交 userId；不按 username 查 IAM，也不创建 IAM 用户副本。
- V1 只允许用户读写自己，全部端点只要求 `isAuthenticated()`，不新增 Preference 管理 Permission。
- Preference 不进入 JWT，不修改 `/api/iam/me`，不保存 Role、Permission、Factory/Party Scope、OAuth
  Client、Token、Session、Credential、Client Secret、JWT Claim 或服务端业务状态。
- Preference 不决定 Factory 业务时区、生产/库存/财务/审批日、金额、数量、单位或授权上下文。

## 4. V1 显示偏好白名单与默认

只支持五个可空用户覆盖字段：

| 字段 | 白名单 | Platform Default |
|---|---|---|
| locale | `zh-CN`、`en-US`，严格匹配 | `zh-CN` |
| displayTimezone | JDK `ZoneId` 可用 IANA Zone ID；拒绝 Offset/GMT+8 | `UTC` |
| themeMode | `SYSTEM`、`LIGHT`、`DARK` | `SYSTEM` |
| density | `COMFORTABLE`、`COMPACT` | `COMFORTABLE` |
| pageSize | `10`、`20`、`50`、`100` | `20` |

数据库 NULL 表示没有用户覆盖；响应 `sources` 对每项返回 `USER` 或 `PLATFORM_DEFAULT`。浏览器 Locale
只能由客户端作为首次候选，用户显式 PUT 后才成为服务端永久偏好。

## 6. 受限 View 类型模型

HTTP、Application 和 Domain 使用明确 Column/Sort/Filter 类型，不接受任意 JSON Object：

- Column：最多 100；columnKey/order 唯一；order 非负；width 50～1000；pinned 为 NONE/LEFT/RIGHT。
- Sort：最多 3；fieldKey 唯一；ASC/DESC；priority 从 0 连续递增。
- Filter：最多 20；Operator 为 EQ/NE/CONTAINS/STARTS_WITH/IN/BETWEEN/IS_NULL/IS_NOT_NULL；
  ValueType 为 STRING/INTEGER/DECIMAL/BOOLEAN/DATE/INSTANT；values 仅标量字符串，单值最多 512 字符。
- 三项受控 JSONB 总编码最大 16 KiB；数据库约束保证 JSON Root 为 Array。

不支持脚本、SQL、正则、Class Name、Java 序列化、深层 Object、Dashboard、Favorites、Menu、Navigation、
Feature Flag 或权限过滤规则。业务查询服务必须把恢复的字段/Operator 再映射到自身白名单并重新授权。

## 7. Secret 与敏感数据防护

applicationCode、viewKey、columnKey、fieldKey 按点/短横线 Segment 拒绝 password、secret、credential、token、
authorization、cookie、session、private-key、api-key、client-secret、JWT、Role、Permission、Scope 等语义。
稳定错误为：`User Preference 不允许保存 Secret、Credential 或 Authorization 数据`。

Filter Value 额外拒绝 Bearer/Basic、JWT-like、access_token、refresh_token、password、client_secret 等明显
凭据形态。该能力不是通用敏感数据仓库，不批准存储完整身份证号或其他未批准敏感信息。

## 8. 版本、首次竞争与 Reset

- GET 无记录：`version=0`、`persisted=false`，返回 Platform Default。
- 首次 PUT：请求 `version=0`；数据库 Unique 竞争统一返回 `409 stale_version`。
- 已有记录：请求必须携带当前 Version；MyBatis-Plus CAS affected rows=0 返回 `409 stale_version`。
- Display Reset：五项覆盖全部置 NULL、Version 递增、审计更新，不删除行。
- View Reset：enabled=false，清空 columns/sorts/filters/pageSize、Version 递增，不删除行；再次保存会重新启用。

不使用 JVM 锁、Redis、Seata 或跨服务事务。

## 9. HTTP API 与稳定错误

显示偏好：

```text
GET  /api/system/preferences/me
PUT  /api/system/preferences/me
POST /api/system/preferences/me/reset
```

视图设置：

```text
GET  /api/system/preferences/me/views/{applicationCode}/{viewKey}
PUT  /api/system/preferences/me/views/{applicationCode}/{viewKey}
POST /api/system/preferences/me/views/{applicationCode}/{viewKey}/reset
GET  /api/system/preferences/me/views?applicationCode={applicationCode}
```

List 强制 applicationCode、只读当前用户、固定 viewKey/id 排序、只返回已启用记录且最多 100 条。响应不返回
数据库 ID 或 userId。错误覆盖 unsupported_locale、invalid_timezone/theme/density/page_size、invalid_application_code、
invalid_view_key、invalid_column/sort/filter_setting、payload_too_large、forbidden_preference_key、stale_version、
not_authenticated；400/401/409/413 按固定矩阵映射，不返回 SQL、表名或 Stack Trace。
