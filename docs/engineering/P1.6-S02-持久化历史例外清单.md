## 4. 已核对的特殊边界（不是待改写违规）

- `IamAuthorizationServerConfiguration` 中的 `JdbcRegisteredClientRepository`、
  `JdbcOAuth2AuthorizationService`、`JdbcOAuth2AuthorizationConsentService` 是 Spring Authorization
  Server 官方 JDBC Store；保留 JDBC，不迁移为 MyBatis-Plus，不强加 `BaseEntity`。
- `JdbcOutboxRepository` 使用参数化 SQL、短领取事务、`FOR UPDATE SKIP LOCKED` 与 affected rows/CAS；
  Broker 调用由 Publisher 在事务外执行，符合 ADR-005/015。
- `InboxDeduplicator` 在同一本地事务写 Inbox 和调用业务动作；唯一冲突承担事件级去重，符合基线。
- IAM 用户、角色、权限软删除表当前业务代码保留永久唯一 code/username 语义；S02 不改 Partial Index。
- `IamSessionTokenService` 的 `noRollbackFor = OAuth2AuthenticationException.class` 用于保留 Refresh 重放/泄漏
  检测后的 COMPROMISED 状态，是安全协议特例；S02 不修改，S09 继续做协议级回归。
