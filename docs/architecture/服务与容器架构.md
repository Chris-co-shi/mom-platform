# 服务与容器架构

> 适用于服务职责、部署单元和服务协作；精确端口与路由读取各模块配置。

## 部署单元

- `mom-gateway`：WebFlux 入口、路由、边缘检查、Header 清洗和限流。
- `mom-auth-server`：身份、权限和 Redis Opaque Token。
- `mom-system-server`：字典、支持 Locale 与 `system.*` 国际化。
- `mom-mdm-server`：静态主数据、制造定义和质量基础定义。
- 其他 `*-server`：独立领域边界；是否已有业务闭环见 [当前实现地图](../当前实现地图.md)。

`*-api` 和 `*-client` 是 Maven 依赖，不单独部署。Server 不依赖其他领域 Server。

## 协作边界

```text
Web/PDA → Gateway → Resource Server
MOM 同步调用 → *-client + mom-openfeign
外部系统 → Integration/Infrastructure Adapter
异步事实 → RocketMQ + Outbox/Inbox
```

- Gateway 不负责最终 Token 认证。
- OpenFeign 只用于 MOM 内部调用，并仅传播当前请求的原始 Bearer。
- SAP、LIMS、PCS、AGV/WCS 不得复用内部用户 Bearer。
- 后台任务没有用户请求时不得伪造管理员或系统 Token。

质量定义归 MDM、运行时质量事实归 QMS，见 [ADR-045](../adr/ADR-045-MDM质量基础定义与QMS运行时边界.md)。
