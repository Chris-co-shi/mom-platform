# 领域边界

> 适用于数据权威和跨服务协作判断；当前实现状态见 [当前实现地图](../当前实现地图.md)。

| 领域 | 权威数据 |
|---|---|
| Auth | 用户、角色、权限、关系和认证 Token |
| System | 平台字典、支持 Locale、`system.*` 国际化 |
| MDM | 组织、仓储静态结构、物料、UOM、制造定义、质量基础定义 |
| MES | 工单、定义快照、投料、过程记录和产出 |
| WMS | 容器、库存流水、余额、预占、锁定和仓储作业 |
| QMS | 检验任务、样本、结果、判定、放行和不合格处置 |
| Integration | 外部端点、映射、请求、重试、补偿和对账 |
| Traceability | 谱系边、影响分析和召回查询模型 |

## 关键分界

- MDM 拥有 Warehouse/Area/Location 等静态身份；WMS 拥有库存、占用和实时可用性。
- MDM 拥有检验特性、方法和质量标准；QMS 引用已发布定义并拥有检验运行时事实。
- MES 拥有工单和执行事实；定义发布在 MDM，工单下达时按业务要求固化引用或快照。
- QMS 不直接更新 WMS 库存；通过事实事件表达处置结果。
- Traceability 不修改 MES、WMS 或 QMS 的来源事实。

对应决策见 [ADR-044](../adr/ADR-044-MDM静态主数据与WMS-MES运行时所有权边界.md)和 [ADR-045](../adr/ADR-045-MDM质量基础定义与QMS运行时边界.md)。

## 跨域依赖检查

新增依赖前必须明确：数据权威、同步校验或状态传播、失败行为、幂等/补偿、历史解释方式，以及是否需要新 ADR。
