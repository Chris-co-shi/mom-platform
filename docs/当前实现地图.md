# MOM Platform 当前实现地图

本文件是稳定实现状态的唯一摘要。精确字段、路径和行为仍以源码、Flyway 与测试为准；不要在其他文档复制本页内容。

## 状态定义

- **已实现**：存在真实入口、持久化或运行时行为及相应验证。
- **骨架**：模块可以构建，但没有可对外宣称的业务闭环。
- **规划**：只存在需求或 ADR，不属于当前能力。

## 运行时边界

### Auth 与 Gateway

- 客户端发送 Bearer Opaque Token；Gateway 不查询 Token Store。
- 目标 Resource Server 使用 Redis-backed Introspector 完成最终认证，并通过 `@PreAuthorize` 授权。
- 内部 OpenFeign 仅传播当前请求的原始 Bearer，不生成系统 Token。
- 当前权限前缀包括 `auth:*`、`system:*`、`mdm:*`。

### System

- 拥有平台支持 Locale、字典以及 `system.*` 动态文案。
- 不拥有应用导航、用户偏好、通用参数或其他业务域的 Translation。

### MDM

- 组织与制造资源：Plant、Workshop、Production Line、Workstation。
- 仓储静态结构：Warehouse、Area、Location Type、Location。
- 物料与计量：Material Category、Material、UOM、Conversion。
- 制造定义：Formula、Routing、Production Version。
- 质量基础定义：Inspection Characteristic、Inspection Method、Quality Specification、Revision 与 Item。
- 质量定义使用 `mdm:quality-definition:read/write` 和 `mdm.*` 国际化 Key；QMS 不再拥有这些 CRUD。
- 编码规则 V1-A：`mom-code-rule` 独立承载公共契约、Handler、Registry、Application 和 JDBC Store，`mom-webmvc` 承载 HTTP 边界；Owner 由服务启动配置决定，固定表名前缀和本地 DataSource/事务绑定，规则管理权限通过 `mom.code-rule.management.read-authority/write-authority` 显式配置且限定当前 Owner；Catalog 保持 Resource Server 认证边界。Handler 与 Provider 自动发现，MDM 自有 JSONB 规则草稿、修订与启停，使用 `mdm:code-rule:read/write`，由 System 前端 `/system/code-rules` 管理。规则身份新增使用场景与纯文本说明，各修订共享；创建和草稿保存必须提供使用场景，旧数据允许为空。正式编号分配和 WMS/MES 生产表尚未实现。

### QMS

- 当前不提供质量基础定义 Controller 或前端管理路由。
- `mom_qms` 中旧定义表由后续 Migration 标记退出；未来运行时质量事实不得写回 `mom_mdm`。
- 未来 QMS 通过 `mom-mdm-api/client` 引用已发布质量标准，具体检验状态机尚未进入当前 Slice。

## 前端对应

`mom-web` 当前提供 IAM、System、MDM 页面。浏览器 API 前缀为 `/auth`、`/system`、`/mdm`；质量定义页面属于 MDM 导航与权限空间。前端的精确状态见其 `docs/frontend/当前实现地图.md`。

## 不应宣称已实现

- MES 生产工单、投料、报工和过程执行闭环；
- WMS 库存余额、预占、移动、冻结和对账闭环；
- QMS 检验执行、结果采集、判定、放行和不合格处置；
- SAP/LIMS/PCS/AGV 的生产级集成；
- 通用工作流、跨服务 Saga 或默认启用的 Seata。
